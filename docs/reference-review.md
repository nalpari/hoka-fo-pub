# 참고 사이트 검토

2026-09-15 자동 조회 기준이다.

- HOKA 메인은 검색 제안, 상품 탐색, 캠페인, 컬렉션, 멤버십/서비스 및 다단 푸터의 흐름을 확인했다. 이 프로젝트는 같은 정보 흐름만 흑백 와이어프레임으로 적용했다.
- HOKA 상품 상세는 갤러리, 색상·사이즈 재고, 장바구니, 설명, 사양, 사이즈, 리뷰 흐름을 확인했다. 옵션별 이미지/재고와 장바구니 목업으로 적용했다.
- HOKA 상품 목록과 New Balance Korea의 메인·상품목록·상세는 자동 조회가 콘텐츠 크기 제한 또는 내부 오류로 확인되지 않았다. 그 세부 UI는 사용자 요구사항의 임시 설계를 적용했다.

참고 사이트의 디자인·이미지·문구는 사용하지 않았다.
