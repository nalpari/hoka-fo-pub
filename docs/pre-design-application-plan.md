# 확정 디자인 전 적용 검토

기준: 개발검수 허브의 화면 검수 목록, 뉴발란스 코리아 공개 사이트맵과 로그인 전·후 헤더, HOKA 글로벌 공개 메뉴·상품 필터 자료 및 2026-09-18에 전달받은 GNB 캡처.

## 결론

확정 디자인 전에는 브랜드 비주얼을 결정하지 않고, 화면 구조와 상태 규칙을 먼저 고정한다. HOKA의 상품 탐색 방식과 뉴발란스의 한국 이커머스 운영 구조를 적용하되, 캠페인 우선순위·키즈 판매 여부·세일 정책은 고객사 결정 후 반영한다.

## 반영 완료: 데스크톱 GNB 메가 메뉴

첨부된 뉴발란스 화면의 **전체 폭 화이트 패널, 활성 메뉴 하단선, 패널 외 영역 딤 처리, 다열 텍스트 중심 레이아웃**을 구조로 적용했다. HOKA 캡처에 있는 분류 체계를 메뉴 데이터로 옮기되, 타사 이미지·문구는 가져오지 않고 HOKA WIRE의 임시 안내 카드로 대체했다.

| 1차 메뉴    | 반영한 2차 메뉴 축                    | 구현 원칙                                                                                           |
| ----------- | ------------------------------------- | --------------------------------------------------------------------------------------------------- |
| MEN / WOMEN | Featured, Activity, Footwear, Apparel | 신상품·베스트, 로드/트레일/하이킹/워킹/트레이닝/라이프스타일, 와이드·안정화·리커버리, 의류·액세서리 |
| SHOES       | Activity, Feel, Model, Essentials     | 활동·쿠셔닝·안정성·발볼·모델(Bondi/Clifton/Speedgoat/Mach)을 독립 탐색 축으로 제공                  |
| EXPLORE     | Guides, Technology, Stories, Support  | 러닝 가이드, 기술 콘텐츠, 러너/이벤트 콘텐츠, 고객지원으로 분리                                     |

메뉴 항목은 현재 구현된 상품 목록 또는 기획전 상세 경로로 연결했다. 상품 목록의 쿼리 값은 이후 실제 필터 API와 연결할 수 있도록 활동·성별·카테고리·쿠셔닝·안정성·발볼·모델 단위로 보존한다. 마우스 오버뿐 아니라 키보드 포커스와 Enter/Space 토글, Escape 닫기, 패널 밖 클릭 닫기를 지원한다. 모바일은 호버를 강제하지 않고 기존 전체 메뉴 진입을 유지한다.

관련 구현 파일:

- `src/shared/components/organisms/Layout/SiteHeader/megaMenu.ts` — 메뉴 IA와 연결 경로 데이터
- `src/shared/components/organisms/Layout/SiteHeader/SiteHeader.tsx` — 접근 가능한 메가 메뉴 상호작용
- `src/shared/styles/global.scss` — 데스크톱 패널·딤·반응형 스타일

## 확정 디자인 전에는 보류할 항목

- 브랜드 컬러, 서체, 사진 톤, 모션 강도, 아이콘 스타일
- 메인 히어로의 카드 수·캠페인 우선순위·배너 자동재생
- GNB의 최종 라벨, 3뎁스 노출 방식, 모바일 메뉴 전환 방식
- 세일을 독립 메뉴로 둘지, 기획전 안에서 운영할지
- 키즈 카테고리의 판매·노출 여부

## 뉴발란스에서 확인한 구조

뉴발란스 코리아의 로그인 전 헤더는 상단 유틸리티(매장찾기·공지사항·FAQ·이벤트), 주 탐색(캠페인·Men·Women·Kids·Sale·런칭캘린더), 검색·로그인·회원가입·장바구니로 구성된다. 로그인 후에는 관심상품과 최근 본 상품 카운트가 추가되고, 로그인/회원가입은 마이페이지로 대체된다.

공개 사이트맵은 Men/Women의 신발·의류·용품·러닝, Kids의 신발·의류·용품, 브랜드 콘텐츠, 고객지원(FAQ, 공지, 1:1 문의, 등급·마일리지, 배송, 세탁, 매장, 약관)을 분리한다. 이 구조는 상품 탐색과 운영성 콘텐츠를 섞지 않는 참고 사례다.

## HOKA에서 가져올 정보 구조

HOKA의 공개 메뉴·상품 탐색 자료와 전달받은 캡처는 성별별로 Featured, Activity, Footwear, Apparel을 나누고, 신발은 Road Running, Trail Running, Hiking, Walking, Lifestyle, Training & Gym, Sandals & Slides처럼 활동 기준으로 구성한다. 모델 라인(Bondi, Clifton, Speedgoat, Mach 등)도 별도 탐색 축이다. 상품 목록은 사이즈·발볼·색상뿐 아니라 Best For, Cushioning, Stability, Heel-to-toe offset 같은 성능 기준을 필터로 제공한다.

이 구조는 HOKA 한국 사이트에서 활동·모델·성능을 독립 데이터로 관리해야 한다는 근거다. 캡처에 있던 Kids와 Sale은 현재 1차 IA 및 운영 정책에 포함하지 않았으며, 판매 범위가 확정될 때만 메뉴 데이터에 추가한다.
