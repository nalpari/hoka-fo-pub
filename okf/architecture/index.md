- [라우팅과 플랫폼](routing.md) - App Router 경로, 마이페이지 러닝세션 신청내역 연결, 페이지 경계와 PC·모바일 선택을 설명한다.
- [공통 상태와 데모 데이터](state.md) - 로그인, 장바구니와 목 데이터의 수명 및 제약과 JSX 스타일 이전 후 상태 계약 유지 검토를 설명한다.
- [컴포넌트와 스타일](ui.md) - 공통 UI 계층, 러닝세션 모바일 목록·상세·고정 신청 바와 기능 내부 레이아웃·필터 책임 분리, 상품 카드 상품명 말줄임, 모바일 전체 메뉴, 마이페이지 내부 구성·선택 레이블 계약, Panda CSS·Storybook의 `src/stories/` 배치 규칙, Components·Features의 JSX 스타일 props 이전과 재사용·구조 조합 점검 결과를 설명한다.
