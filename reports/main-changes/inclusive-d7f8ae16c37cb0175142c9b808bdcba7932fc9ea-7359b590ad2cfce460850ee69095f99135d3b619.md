## 공통 영향과 연결 범위

공통 Typography·Button·Badge·ModalDialog·Breadcrumb·HelpTips·상품 카드와 사이즈 선택 변경은 직접 수정된 공용 파일로 한 번 표시했다. 메뉴가 공통 UI인 항목은 B/T 전체 import 그래프에서 얻은 영향 가능 화면을 기준으로 담당자를 연결했다. 전역 레이아웃의 간접 의존은 개별 화면 직접 수정으로 표시하지 않았다.

실적 0%인 상품 상세·상품 목록·런칭캘린더·쿠폰·프로필·리뷰·러닝세션 등 화면 전용 변경은 제외했다. 공용 목록 파일의 검색 결과 연결과 주문·검색에서 쓰는 공용 UI는 유지했다. 사이즈가이드 측정 이미지 삭제는 해당 IA의 WBS가 미등록이므로 보고에 남겼다. 동적 문자열 참조는 정적 그래프로 모든 런타임 영향을 증명할 수 없다.
